版本族谱 · Versions

《三国演义》版本源流复杂：从明代嘉靖壬午本（1522）到清初毛宗岗评本，再到当代沈伯俊校理本。本工程以毛本为唯一全本底本（★），其余版本保留元数据以待扩展。

  1. 版本系统

    • 演義系（通俗演義）（嘉靖壬午本）：24卷240則、單題七言；少花關索；關公封漢壽亭侯有改印細節；靜軒詩少；文字較雅。
    • 志傳系（三國志傳）（建陽刻本群）：20卷240則；含『花關索出身傳/征西川/下荊州』等花關索四傳；靜軒周靜軒詩多；文字質樸；部分記事更接近早期講史。
