演義系（通俗演義）族譜

祖本：嘉靖壬午本

特徵：24卷240則、單題七言；少花關索；關公封漢壽亭侯有改印細節；靜軒詩少；文字較雅。

演義系從嘉靖壬午本（1522）發軔，經周曰校萬卷樓本（1591）、李卓吾評本（約1620）增補評點與合回為一百二十，至清初毛宗崗評本（1679）定型，遂成通行本三百餘年。

志傳系（三國志傳）族譜

祖本：建陽刻本群

特徵：20卷240則；含『花關索出身傳/征西川/下荊州』等花關索四傳；靜軒周靜軒詩多；文字質樸；部分記事更接近早期講史。

志傳系以閩建刻本為主（葉逢春、余象斗、黃正甫、劉龍田、朱鼎臣），保留民間說書痕跡與花關索故事，文字質樸，是研究《三國》成書史的重要資源。

嘉靖壬午本《三國志通俗演義》（1522）

元數據已收 24卷240則，每則單題七言 足本，多影印本與現代排印本

刊者：不題撰人，序題『晉平陽侯陳壽史傳，後學羅本貫中編次』　刊行：明嘉靖元年壬午（1522）司禮監刊本一說為民間刻本

典藏：現存多個藏本，最著名者為上海圖書館藏本、國家圖書館藏本；人民文學出版社1975年影印本行世最廣

版本特徵

  • 現存最早的《三國演義》刻本，一般視為最接近羅貫中原作的版本
  • 卷首有弘治甲寅（1494）庸愚子蔣大器序、嘉靖壬午（1522）修髯子張尚德引
  • 每則末尾常以『試看後事如何，且聽下回分解』『後人有詩曰……』收束
  • 關公降曹後封『壽亭侯』，關公不拜，曹操改鑄『漢壽亭侯之印』，關公方拜
  • 諸葛亮上方谷設計火攻，意欲燒死魏延，因天降大雨未果
  • 呂布被擒時罵劉備『是兒最無信者！大耳兒，不記得轅門射戟時耶？』
  • 無楊慎《臨江仙》開篇詞，無毛宗崗增刪的回目對偶
  • 靜軒詩、唐庚詩較毛本多，若干處仍保留『史官曰』『論曰』史論體

與毛本主要差異

  • 【改印】嘉靖本有曹操初鑄『壽亭侯』印、關公不拜、改為『漢壽亭侯』方受的細節，毛本刪
  • 【燒魏延】嘉靖本記孔明欲燒魏延於上方谷，毛本刪
  • 【呂布罵劉備】嘉靖本呂布臨刑罵『大耳兒』更直白，毛本略作潤色
  • 【曹操名言】嘉靖本作『寧使我負天下人，休教天下人負我』，毛本作『寧教我負天下人，休教天下人負我』，個別版本作『寧可我負人，毋人負我』
  • 【關公辭曹】嘉靖本關公掛印封金有詳細書信往返，毛本簡化
  • 【回目】嘉靖本單題七言（如『祭天地桃園結義』），毛本改為雙句對偶一百二十回

周曰校本《新刊校正古本大字音釋三國志通俗演義》（1591）

元數據已收 12卷（實多以10-12卷合刻）240則 足本；識典古籍已全文數字化

刊者：明書林周曰校刊行（金陵萬卷樓）　刊行：明萬曆十九年辛卯（1591）金陵萬卷樓刊

典藏：國家圖書館、台北故宮博物院、日本內閣文庫多有藏本；北京大學圖書館藏本較完整；識典古籍據國內藏本掃描OCR免費公開

識典古籍（shidianguji.com）提供免費全文閱讀（周曰校本），但因分頁與反爬限制，本站尚未批量抓取全文。可手動下載其OCR文本後放入 raw/zhouyuexiao/ 目錄，運行 build 腳本即可自動對照入庫。

版本特徵

  • 嘉靖本系統後期最重要的翻刻本之一，加了音注、釋義、考證
  • 刻本版心題『三國志傳』，實為演義系與志傳系的過渡形態
  • 對嘉靖本的訛字有所校正，是李卓吾評本的底本來源之一
  • 牌記題『是書也，刻已數種，悉皆訛舛……敦請名士，按鑑參考，再三讎校』

與毛本主要差異

  • 底本早於毛本近90年，保留演義系早期面貌；評點尚未系統化。

李贄評本《李卓吾先生批評三國志》（1620）

元數據已收 120回（或240則） 多本傳世，現代影印本可見

刊者：　刊行：明末吳觀明、容與堂等多處刊本

典藏：國家圖書館、日本內閣文庫；中華書局、齊魯書社有排印本

版本特徵

  • 首次將240則合併為120回，雙回目對偶，直接影響毛本
  • 有眉批、夾批、回末總評，開啟《三國》評點之風
  • 評點觀點傾向『反道學』，對曹操、劉備、諸葛亮皆有調侃
  • 葉晝（文通）、鍾惺、袁宏道一脈評點風格

與毛本主要差異

  • 毛宗崗本係在李卓吾評本基礎上『奪胎換骨』：保留120回結構，但大量改動評點、刪去李評、插入毛氏自己的總論與評語；尊劉貶曹傾向更為明顯。

毛宗崗評本《四大奇書第一種三國演義》（1679）

★ 已收全文 120回，雙句對偶回目 足本，最通行版本；★本站已收錄全文59萬字

刊者：毛綸（聲山）、毛宗崗（序始）父子評定，題『聖歎外書』（偽託金聖歎）　刊行：清康熙年間醉耕堂、映旭齋等多個刊本

典藏：海內外公私圖書館多藏；人民文學出版社1953年起多次整理校訂本，為最通行讀本

全文來源：Project Gutenberg #23950（繁體排印本），經 opencc 繁轉簡、自動切分為120回

版本特徵

  • 今本《三國演義》的標準形態，通行三百年
  • 卷首加楊慎《臨江仙》（『滾滾長江東逝水』）作為開篇詞
  • 卷末『鼎足三分已成夢，後人憑吊空牢騷』二詩收束
  • 刪去嘉靖本『關公改印』『孔明欲燒魏延』等細節
  • 對回目進行對偶化修辭加工（如嘉靖本『祭天地桃園結義』改為『宴桃園豪傑三結義，斬黃巾英雄首立功』）
  • 增加『讀三國志法』（毛宗崗自序與凡例），強調正統論、關鍵伏筆、首尾照應
  • 評點全面替換為毛氏父子觀點，以『尊劉貶曹』為核心

葉逢春本《新刊通俗演義三國志史傳》（1591）

元數據已收 10卷（一說20卷）240則 孤本、國內罕見；江蘇古籍出版社有標點排印本

刊者：元峰子葉逢春重刊　刊行：明萬曆二十年（1592？），書林葉逢春刊

典藏：西班牙愛斯科里亞爾（Escorial）修道院藏孤本；1990年代由陳翔華等國內學者介紹回國；國家圖書館有膠捲

版本特徵

  • 現存唯一可見的元代遺風『志傳系』早期刻本之一
  • 目錄題『新刊通俗演義三國志史傳』，正文前有元鍾陵張元益序
  • 含『靜軒先生』『東坡先生』『菊東先生』等多個署名的詩讚
  • 部分文字比嘉靖本更為質樸，可能保留更早的說書痕跡
  • 花關索情節在志傳系中最為完整
