如何使用本站

  1. 新手入门：先读首页的五个卡片入口，了解整体结构；可从全文阅读开始，120 回分回展开。
  2. 研究者：先看本体论理解数据模型，然后去查询台用 SQL 直接查询 19 张 Parquet 表，或下载 graph.json 做网络分析。
  3. 文学爱好者：推荐人物志（支持筛选正史/虚构）、战役史、诗词回目、天命叙事四个入口。
  4. 版本学/校勘学：版本族谱+异文对勘，展示嘉万旧本与毛宗岗本的改写差异。
  5. 可视化探索：人物关系网络、时空地图提供 D3 力导向图与 Leaflet 地图。
  6. 数据复用：19 张 Parquet 表位于 docs/data/*.parquet，可直接被 pandas/DuckDB/PyArrow 读取；TBox 本体 TTL 可导入 Protegé 做推理。

与姊妹项目的关系

本工程是继《红楼梦》（The Story of the Stone）与《西游记》（The Journey to the West）之后的第三部数字人文经典重构建，与《水浒传》All Men Are Brothers 本体共用 *_ 前缀 ID 体系（三国为 sg_，水浒为 sh_），未来可做跨本体联动查询（如"关羽与武松的忠义叙事比较""诸葛亮与吴用的军师形象"）。
