底本选择

本文在线全文采用毛宗岗评本（1679年刊）整理，回目对偶、开篇临江仙、尊刘贬曹倾向均为毛本特征； 若要读更接近罗贯中原始版本，请参看「版本族谱」中的嘉靖本《三国志通俗演义》（1522）。 学术阅读推荐沈伯俊校理本（凤凰出版社），订正了毛本若干地理与人物讹误。

数据与接口

所有数据均开放在 docs/data/ 目录下，可直接以 JSON / Parquet 两种格式下载复用。Parquet 可直接在查询台通过 SQL 调用。本体 TTL/YAML 从「本体论」页下载，可在 Protégé 中打开。

本站以毛宗岗评本百二十回为在线全文（590,968字）；本体论（OWL 2）兼容嘉靖本/周曰校本/叶逢春本/黄正甫本/余象斗本/李卓吾评本/李渔评本/毛宗岗本/人民文学出版社本等12个主要版本。

工程以 yejinlei 西游记本体论（jtw_kg_ontology.ttl）为范式，面向多版本对照与异文比对场景扩展；视觉系统参考《石头记》数字人文站。
