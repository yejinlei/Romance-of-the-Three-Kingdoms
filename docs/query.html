本體查詢控制台

所有知識庫數據已離線打包為 19 張 Parquet 表，由 DuckDB-WASM 在你的瀏覽器內完成 SQL 計算，無需服務器，所有數據不下發到任何後台。加載約 3–8 秒（取決於網速），首次需下載約 2MB 數據。

技術範式參考 yejinlei/the-journey-to-the-west：DuckDB-WASM + Parquet + Hash Router + Service Worker。OWL 2 本體在 TTL 文件中規範，數據按 10 大頂級類 / 24 種有向關係入庫。
