OWL 2 DL 推理約束

OWL 2 DL CONSTRAINTS
  • 類不相交：Person ⊓ Place ⊑ ⊥、Battle ⊓ Event ⊓ ⊥……
  • 函數屬性：bornIn Functional、inFamily Functional、hasFullText Functional
  • 反函數：personId InverseFunctional、editionId InverseFunctional（主鍵）
  • 對稱屬性：spouseOf / swornBrotherOf / correspondsTo
  • 傳遞屬性：parentOf⁺ / derivedFrom⁺ / locatedIn⁺（可做祖先與版本溯源推理）
  • 互逆對：lordOf ≡ vassalOf⁻ / memberOf ≡ hasMember⁻ / contains ≡ containedIn⁻
  • 數據約束：Person ∋ mention_count xsd:integer、Edition ∋ year xsd:gYear
