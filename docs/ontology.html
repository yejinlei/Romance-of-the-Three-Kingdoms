本体论构建 · Ontology

本工程采用 OWL 2 DL 形式化建模，TBox 与 ABox 严格分离。TBox 文件位于 03_本体论规范/sanguo_kg_ontology.ttl，受控词表位于 03_本体论规范/vocabularies.yaml。

3. 数 据 属 性 与 受 控 词 表

四级核实度：verified_primary（原文可证）/ verified_commentary（毛评可证）/ scholarly_consensus（学界共识）/ inferred（推理得出）。

虚实标注 fictional_flag：0 正史有其人其事；1 正史有其人但演义有艺术加工；2 纯虚构人物/事件。

4. 版 本 族 谱 层

新增 VersionFamily / Edition / Volume / Chapter / Paragraph / VariantReading / Commentary 七类，构成多版本异文对勘的谱系基础。目前毛本有全本（★），其余版本保留元数据与 8 组学术考证异文。
