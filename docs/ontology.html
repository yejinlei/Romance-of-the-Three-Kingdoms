五、OWL 2 DL 推理約束

  • 類不相交（DisjointClasses）：Person / Faction / Battle / Place / Event / Scholar / AcademicWork / Adaptation / Artifact / LiteraryWork 互為不相交類，推理可檢測跨類實例衝突。
  • 函數/反函數屬性：versionId / personId / forceId / battleId / locationId / eventId / scholarId / paperId / adaptId / artifactId 均為 owl:InverseFunctionalProperty，確保全局主鍵唯一。
  • 對稱屬性：swornBrotherOf / enemyOf_person / kinOf / alliedWith / enemyOf_force / debatesWith / correspondsTo。
  • 傳遞屬性：derivedFrom（版本演化可追溯）。
  • 互逆屬性：masterOf↔apprenticeOf、lordOf↔ministerOf。
  • 跨本體聯動：聲明 sh: 命名空間（水滸本體），人物/地名 ID 可跨棧 JOIN（例如 sg:person_caocao 與 sh: 中相關人物若有歷史關聯，可附加 owl:sameAs 鏈接）。
