本體論規範 · TBox 完備定義

本體採用 OWL 2 DL 描述邏輯規範，10 大頂級實體類，所有子類均繼承自對應頂級類；與水滸本體共享統一 ID 命名規則（sg_xxx_yyy），實現跨本體無縫聯動；可直接導入 Neo4j 與 DuckDB，無需二次重構。

OWL 公理

  • • 10 大頂級類互相不相交（owl:AllDisjointClasses），推理機可識別跨類衝突；
  • • 所有主鍵（xxx_id）同時為 owl:FunctionalProperty + owl:InverseFunctionalProperty，保證唯一性；
  • • derivedFrom 為 owl:TransitiveProperty（版本演化鏈可推理）；
  • • swornBrotherOf / enemyOf_* / alliedWith / kinOf / debatesWith 為 owl:SymmetricProperty；
  • • masterOf / lordOf 顯式定義 owl:inverseOf；
  • • 枚舉受控詞表：核實狀態（4）、異文類型（7）、關係權重（3）、版本族系（4）、五大歷史階段。

跨本體聯動

ID 命名規則 sg_person_xxx 與水滸本體 sh_person_xxx 同構，在 DuckDB/Neo4j 中可直接以 person_id JOIN 實現跨四大名著本體的人物/地名/器物/關係聯查，無需二次重構。

本頁呈現的即為完備 TBox 規範；ABox 實例數據（人物、戰役、地點等）由構建腳本從原文抽取並寫入 Parquet/JSON，可在「本體查詢」頁用 SQL 直接查詢。
