📚 多版本本體框架

本體論 OWL 2 建模，兼容 12 個明清主要刊本，分屬演義系（嘉靖壬午本→周曰校本→李卓吾評本→毛宗崗本）與志傳系（葉逢春本→黃正甫本→余象斗本）兩大版本族。

新增類：VersionFamily / Edition / Volume / Chapter / Paragraph / VariantReading / Commentary，支持版本源流（derivedFrom）、跨版本回目對應（correspondsTo）、異文類型與文獻學意義標註。
