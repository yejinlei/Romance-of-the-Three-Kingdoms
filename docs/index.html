研究说明

本站参照《The Story of the Stone》与《The Journey to the West》两个数字人文工程的构建范式——宣纸式阅读视觉、24 研究入口、OWL 2 本体驱动、多版本异文对勘、学术成果层——以明罗贯中《三国演义》毛宗岗评本为底本，做「文本 + 本体 + 图谱 + 地图 + 查询」五位一体的可复现数字人文研究。

技术栈：纯静态、无服务器、DuckDB-WASM + Parquet 浏览器端列式查询（不使用 Neo4j）；sg_ 前缀 ID 体系与《水浒传》本体 sh_ 技术栈完全兼容，可跨本体联动。

  • TBox 本体层：sg:Character / sg:Faction / sg:Place / sg:Battle / sg:Event / sg:Stratagem / sg:Artifact / sg:Prophecy / sg:Version / sg:Scholarship 十大类 + 24 种对象属性（含 6 种三国专属：效忠/割据/联姻/诈降/挟令/禅代）
  • ABox 实例层：455 位人物（337 正史 / 64 半虚构 / 54 纯虚构）· 191 处地名（191 带坐标）· 115 场战役 · 107 件事件 · 27 计 · 12 谶语 · 17 器物 · 15 学者 · 12 论著 · 17 衍生作品
  • 版本族谱：16 个版本节点，从嘉靖壬午本（1522）到今本沈伯俊校理本；嘉靖本/李卓吾评本/毛本/沈校本四大核心版本。
  • 虚实标注：全部实体加注 fictional_flag：0=正史有其人其事，1=正史有其人但演义加工，2=纯虚构（如貂蝉、周仓、关索）。
