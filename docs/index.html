滾滾長江東逝水　浪花淘盡英雄
是非成敗轉頭空　青山依舊在　幾度夕陽紅
白髮漁樵江渚上　慣看秋月春風
一壺濁酒喜相逢　古今多少事　都付笑談中

本工程以羅貫中《三國演義》毛宗崗評本為核心文本，效法 yejinlei《紅樓未完》本體論與 視覺範式，先立 OWL 2 DL 本體（10 大頂級類、35 對象屬性、24 種核心關係，其中 6 種三國專屬）， 再以多 Agent 互相質證：版本學家、評點家、文史互證學者、知識圖譜工程師。 毛宗崗定本為正統，嘉靖本/葉逢春本/李卓吾評本/沈伯俊校理本並列作異文對勘。
